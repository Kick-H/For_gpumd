Test for ensemble command `heat_nhc_power`

Add a new ensemble command `heat_nhc_power` for non-equilibrium molecular dynamics (NEMD) thermal transport simulations. Instead of imposing a temperature difference between the heat source and sink (as in `heat_nhc`), this method drives heat transport with a constant heating power `P` (in eV/fs, total for the whole group, not per atom). Every MD step, an energy `dE = P * dt` is added to the source group and removed from the sink group by scaling the velocities about each group's center-of-mass velocity, so no net momentum is injected. Because no thermostat acts on the source/sink, the accumulated `energy_transferred` (reported in `thermo.out`) is exactly the explicitly injected/removed energy, making the steady-state heat current known by construction rather than measured a posteriori. Syntax (analogous to `heat_nhc`): ensemble heat_nhc_power T T_coup power source sink * `T` : average/target temperature in K (used for output and velocity initialization only; no thermostat acts on source/sink) * `T_coup` : parsed for syntax compatibility with `heat_nhc`, NOT used * `power` : heating power P in eV/fs (total for the group); stored internally in `delta_temperature` * `source` / `sink` : group IDs (grouping method 0) Guards for pathological states: the sink never loses more kinetic energy than it has, and a zero-kinetic-energy source is never heated; the energy accounting always uses the actual energies transferred, so any guard activation shows up directly as a deviation from `+/- P * t`.
